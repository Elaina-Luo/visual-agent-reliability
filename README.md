# Visual Agent Reliability

A research-oriented multimodal agent project investigating whether
explicit action verification and bounded retry improve reliability
under controlled click failures.

## Task

Select two specified visual objects in a browser environment,
submit the selection, and finish.

## Methods

- B0: Reactive agent
- B1: Verification only
- B2: Verification with bounded retry

## Status

Project setup in progress. No experimental results yet.
